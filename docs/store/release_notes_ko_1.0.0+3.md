# PROJECT GTG 릴리즈 노트 — 1.0.0+3

릴리즈 날짜: 2026-04-20

## 개선 사항
- **Android 15 대응 강화**: 더 넓은 화면(edge-to-edge) 환경에서 화면이 더 자연스럽고 안정적으로 표시되도록 조정했습니다.
- **상단/하단 시스템 바 표시 개선**: 최신 Android 기기에서 상태 표시줄과 내비게이션 영역이 앱 화면과 더 잘 어울리도록 다듬었습니다.
- **리마인더 안정성 개선**: 앱이 다시 열릴 때 알림 동기화가 중복 실행되지 않도록 정리해, 불필요한 지연과 일시 멈춤 가능성을 줄였습니다.
- **전반적인 품질 개선**: 최신 Android 동작 변경에 맞춰 레이아웃과 실행 흐름을 점검하고 안정성을 높였습니다.

## 사용자용 짧은 버전
- Android 15 화면 표시와 리마인더 안정성을 개선했습니다.

## Play Console용 짧은 문구 후보
- Android 15 호환성과 전체 화면 표시를 개선하고, 리마인더 안정성을 높였습니다.
